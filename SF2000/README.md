# DY19 on SF2000
[bisrv_DY19_to_SF2000_918Mhz.asd](https://github.com/Trademarked69/Frankenstein-Froggy-Firmware/blob/main/SF2000/bisrv_DY19_to_SF2000_918Mhz.asd) is DY19 with patched buttons and clock speed set to 918 MHz for SF2000. This was made by [osaka](https://github.com/bnister).   

# GB300 V1 on SF2000
[bisrv_GB300V1_to_SF2000.asd](https://github.com/Trademarked69/Frankenstein-Froggy-Firmware/blob/main/SF2000/bisrv_GB300V1_to_SF2000.asd) is GB300 V1 with patched buttons screen and sound for SF2000. This was made by [osaka](https://github.com/bnister).   

This uses the same screen as the SF2000 so you must revert [this patch](https://github.com/tzubertowski/gb300_multicore/commit/0d8b553) when building GB300 multicore and all cores must be rebuilt.  

# GB300 screen in SF2000
[bisrv_GB300_screen_in_SF2000.asd](https://github.com/Trademarked69/Frankenstein-Froggy-Firmware/blob/main/SF2000/bisrv_GB300_screen_in_SF2000.asd) SF2000 with the GB300 screen and the snes emulator fix. This was made by [dteyn](https://github.com/Dteyn).   

This uses the same screen as the GB300 so you must apply [this patch](https://github.com/tzubertowski/gb300_multicore/commit/0d8b553) when building SF2000 multicore and all cores must be rebuilt.
